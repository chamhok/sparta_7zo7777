# 카드뒤집기 게임이다 냥
스파르타 7조(6조)의 카드 뒤집기 게임 과제입니다.

## 프로젝트 소개
카드 뒤집기 게임을 만들어보았습니다. 개발에 참여한 인원들의 얼굴이 카드로 이루어져 있으며, 중간에 특별한 카드(고양이)도 있습니다.
갤러리 기능과 시작화면 미니게임도 특별하게 만들어보았습니다.

## 개발 기간
23.10.30 ~ 23.11.03

## 개발 환경
Unity ver. 2022.3.11f1
Window 10

## 구현 기능
- 인게임 
  - 카드 뒤집는 애니메이션
  - 제한 시간
  - 남은 시간 시각화(일정 시간 이하로 남은 경우 화면이 붉게 변함)
  - 틀리는 경우 남은 시간 감소
  - 한번이라도 뒤집어본 카드는 회색으로 변경
  - 매칭 실패시 **땡!** 표시
  - 매칭 시도 횟수 표시
  - 카드 오픈 후 5초 동안 가만히 있을 경우 카드 다시 닫힘
  - 다시하기 버튼 추가
  - 설정창 버튼 추가
  - 카드 이미지 추가 -> 이미지들 중 랜덤으로 8개 표시
  - 고양이 매칭 실패시 고양이 숨기. 이때 다른 카드 중 하나와 고양이가 위치가 바뀜

- 게임 종료 시
  - EndPanel에 횟수, 점수 표시

- 시작화면
  - 소리 조절 기능
  - 게임 시작 버튼
  - 본 게임 난이도 조절 버튼
  - 갤러리 이동 버튼
  - 미니게임(화살 피하기 게임)
    - 시간이 갈수록 난이도 상승
    - 무한 배경
    - 미니게임 최고점수
    - 캐릭터 남은 체력
    - 회복 물약을 먹을 경우 체력 회복
    - 캐릭터 사망시 애니메이션, 효과음
    - 미니게임 다시하기 버튼

- 갤러리
  - 인물 설명 확인
  - 해금 여부 확인
  - 메인 화면으로 돌아가기 버튼
